# OncoMosaic 项目学习与讲解手册

这套文档面向需要理解项目、演示功能、阅读实现或准备面试的开发者。内容基于已提交的工程实现；医学概念单独引用一手资料。**本项目使用合成数据和模拟算法，不是经过医学性能验证的肿瘤诊断系统。**

技术主线：React + TypeScript + SVG → ASP.NET Core / .NET 10 → MySQL 8.4；独立 Python FastAPI 服务处理模拟图像分析，Docker Compose 管理四个服务。

文档包含 6 个主题章节、14 张 Mermaid 架构/关系/流程图，以及 5 张新增操作截图；还引用了此前的完整浏览器验收截图。

## 先看一个完整例子

![实际浏览器中选择核对象、复核并查看统计](browser-workflow.png)

在同一个工作空间，左侧选择图像和 ROI，中央查看原图及细胞叠加，右侧修改显示或复核对象，底部查看同一任务、同一复核版本的统计。此图来自浏览器实际验收，使用的是 `170×138 px` 的 ROI，检测 61 个核，排除 1 个后有效核数为 60。

[API 验收记录](api-verification.json)使用另一块 `180×160 px` 的 ROI，得到 69 个核。这两组数值对应不同区域，不能混用，也不代表医学准确率。

## 推荐阅读顺序

- **第一次看项目（约 20 分钟）**：01 → 02 → 03，先弄清业务对象与使用流程。
- **准备讲实现（约 35 分钟）**：04 → 05，沿源码入口核对关键逻辑。
- **准备面试（约 20 分钟）**：06，练习后回到 04 查证回答，按真实参与情况调整措辞。

所有流程图均为 Mermaid 源码，可直接在 GitHub 渲染。截图是本地真实页面，既包含此前的浏览器验收截图，也包含本次文档采集的界面状态；不是设计稿。截图中的 ROI 草稿未保存，不代表新分析结果。
