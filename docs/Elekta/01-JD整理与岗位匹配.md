## 1. 截图内容

**标签：**C#、C++、C#开发经验、MySQL、.NET开发经验、SQL Server、计算机相关专业。**毕业时间：2026年。** 标签不等于团队一定同时使用所有技术。

**职位概述：**Elekta是一家总部位于瑞典、长期深耕放射治疗领域的国际化解决方案公司。加入后将参与核心放疗系统MOSAIQ的开发与维护，涵盖新功能实现、问题定位修复及系统持续演进，并与全球工程团队协作，构建高质量、长期可维护的临床级医疗软件。

**主要职责：**

1. 基于需求与技术方案，设计、实现并维护软件功能。
2. 参与技术方案讨论，推动合理的实现决策与落地。
3. 定位并修复开发、测试或生产环境中发现的软件缺陷并优化。
4. 支持客户升级/投诉问题调查：复现问题、根因分析（RCA），制定并实施纠正措施。
5. 与质量工程团队协作，支持验证活动，满足质量与合规/法规要求。
6. 进行代码评审，遵循既定编码规范与研发最佳实践。
7. 编写与维护技术文档，包括设计、实现、缺陷修复与问题分析。
8. 持续改进研发流程、工具链与工程实践。
9. 遵循质量管理体系（QMS）要求及适用法规标准。

**任职要求：**

- 计算机科学、软件工程或相关专业本科及以上；优秀应届毕业生也可。
- 1–2年相关软件开发经验。
- 扎实的面向对象编程基础与软件设计能力，理解常见设计模式与良好代码规范。
- 熟练使用C++或C#或Java或同类语言开发。
- 有关系型数据库与SQL经验，熟悉Git等版本控制工具。
- 英语听说读写流利，可在全球化研发组织中进行书面及口头沟通。
- 分析与解决问题能力强，能独立推进，也能高效协作。

**优先考虑：**.NET开发；敏捷/Scrum；自动化测试；CI/CD及自动化构建测试；Web Service/API；云端或分布式架构；受监管、安全关键或严格质量体系的软件环境；故障排查/RCA；DICOM/HL7/FHIR等医疗信息化标准或临床系统知识。

## 2. 怎么分配准备精力

| 优先级 | 考点与理由 | 需要准备的证据 |
|---|---|---|
| P0 | OOP/软件设计：正文硬要求 | EasyAccess公共流程与变化点，解释模式取舍 |
| P0 | SQL和一致性：正文硬要求 | JOIN/聚合/分页/索引/事务；写出并发更新SQL |
| P0 | 缺陷定位与维护：职责反复出现 | 退款竞争的现象、机制、复现和修复边界 |
| P0 | 英语：明确要求 | 自我介绍、项目、澄清问题、简短状态汇报 |
| P0 | 质量意识：业务场景核心 | 需求—变更—测试—发布证据如何关联 |
| P1 | C#/.NET：标签突出、正文加分 | 值类型、资源释放、async/await、LINQ、DI |
| P1 | Git/测试/CI与API | 一次小改动如何审查、回归、交付 |
| P2 | 医疗标准和云架构 | 分清术语、说明接入验证；不背条文 |
| P2 | Agent/RAG | 作为学习和工具能力补充，面试官感兴趣再展开 |

优先级来自JD匹配，不代表题目出现概率。C++和C#不必同时突击；先确认团队语言。Java被正文明确接受，但是否需要入职后转栈仍待确认。
