# Elekta｜模拟面试与面前速记

根据JD设计的练习，不是Elekta历年真题；轮次和语言未知。

## 1. 60分钟模拟

| 时间 | 主问题 | 检查点 |
|---|---|---|
| 0–5分钟 | 英文介绍，为什么Elekta | 能讲岗位动机，不把岗位说成AI研发 |
| 5–15分钟 | 选一个项目，个人贡献是什么 | 背景、难点、证据、选择、验证、边界完整 |
| 15–25分钟 | 退款多锁问题，超时是否重试 | 分清锁顺序、租约、幂等、未知结果 |
| 25–35分钟 | C#异步/资源/DI，OOD | 能迁移Java经验，也能说明语言差异 |
| 35–43分钟 | 写SQL：每人最近一条记录；并发更新 | 窗口函数、稳定排序、影响行数 |
| 43–53分钟 | 升级后记录不显示，如何调查 | 先影响与证据，再假设与验证；留痕协作 |
| 53–57分钟 | 用英文汇报上述缺陷 | 区分observed、suspected、confirmed |
| 57–60分钟 | 反问 | 问团队实际工作和入职期望 |

自评分五项，各0–2分：事实准确、结构清晰、技术解释、异常/验证、英语表达。0分表示无法回答，1分需提示，2分可独立说明。总分是自测工具，不预测录用结果。录音后只优先修最弱两项。

## 2. 面前10分钟

1. **定位：**Java业务开发＋长期维护与排障能力，C#/.NET和医疗质量流程是学习增量。
2. **主项目：**接口兼容迁移、退款锁顺序、EasyAccess规则与模板方法。
3. **迁移关键词：**原契约、差异比较、灰度、回退；共库，不是数据库迁移。
4. **退款关键词：**单条消息、消费者整组、排序后才拿第一锁、扫描重投、超时单退；不是永久阻塞死锁，排序不等于幂等。
5. **异步：**await不自动开线程；取消不回滚远端动作；并发需要限额。
6. **SQL：**JOIN语义、窗口函数、稳定分页、索引与计划、版本条件更新。
7. **RCA：**影响→证据→复现→根因→措施→回归→记录。
8. **质量：**需求和风险要能关联到实现及验证；修复不等于立即发布。
9. **产品：**MOSAIQ相关OIS支撑肿瘤诊疗信息与工作流；不把它等同于放疗设备或治疗计划算法。
10. **英文：**一句结论＋一个例子＋一个边界；不需要复杂词。

## 3. 反问：按剩余时间选三题

- 这个岗位负责MOSAIQ哪一部分，主要服务哪些用户工作流？
- 团队当前主要语言和框架是什么？Java背景成员通常如何过渡？
- 新功能、存量维护和客户问题调查的工作比例如何？
- 开发与质量工程如何协作，一次缺陷从调查到发布通常有哪些阶段？
- 前三个月希望新人独立完成什么？英文协作主要发生在会议还是文档中？

英文可用：

> Which part of MOSAIQ would I work on?
>
> How do developers and quality engineers work together on a defect?
>
> What would you expect me to deliver in the first three months?

## 4. 最容易说错的八点

- 不把MOSAIQ与SmartClinic、治疗计划系统或放疗设备混为一谈。
- 不声称JD证实了ASP.NET Core、微服务或某个.NET版本。
- 不把AI课题说成医疗AI或生产系统。
- 不把退款加锁排序说成完整的exactly-once资金保证。
- 不把模板方法包装成独立设计整个订单中台。
- 不把学习过C#说成已有.NET生产项目。
- 不把设计建议、示例参数和推演测试说成实际实施结果。
- 不为了岗位改写真实离职原因；确认自己是否接受日常维护职责。
