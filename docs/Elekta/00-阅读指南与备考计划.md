**有 Java 业务开发经验、重视兼容性与问题定位、愿意学习 C#/.NET 和医疗软件质量流程的软件工程师。** 主讲接口迁移、退款并发、EasyAccess；Agent/RAG 作为补充。JD 未要求做 AI，不要将医疗软件岗位包装成 AI 岗。

## 时间有限时怎么准备

- **30分钟：**06速记 → 05自我介绍与动机 → 08增强版项目口述。
- **一天约6小时：**01与07共40分钟；02项目60分钟；03技术90分钟；04场景60分钟；05英文50分钟；06模拟60分钟。
- **三天：**第一天岗位与项目；第二天C#、SQL和质量场景；第三天英文录音、模拟面试、补最弱两项。

每天留下可检查产物：一段90秒录音、一张问题时间线、一条手写SQL、一份缺陷分析。不要只收藏资料。

## 待补充信息

面试时间、面试语言、是否有上机、允许使用的语言、团队具体模块，以及个人实际C#学习进度。未获这些信息前，默认以Java展示已有深度，以C#基础证明迁移准备，不预设已具备.NET生产经验。
