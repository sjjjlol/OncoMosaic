# OncoMosaic 英文面试话术

按项目已实现的功能整理，采用简短、易说的英文。涉及个人贡献时，请按实际职责调整。

## 1. 项目介绍｜约 45 秒

**Tell me about your project.**

> OncoMosaic is a research prototype for analyzing multiplex immunofluorescence images of tumor tissue.
>
> Users can upload images, select regions of interest, measure marker signals, review individual objects, and compare two regions.
>
> The frontend uses React and TypeScript. The backend uses ASP.NET Core and MySQL, with a separate Python service for image analysis.
>
> A key feature is traceability. Each result keeps its analysis settings and review version, so users can trace summary statistics back to individual objects.
>
> The current prototype uses synthetic data and a deterministic analysis pipeline. It demonstrates the workflow, but it has not been clinically validated.

## 2. 技术架构

**How does the system work?**

> The React frontend handles image viewing and user interaction. The .NET backend manages data, analysis jobs, statistics, and exports. The Python service handles image processing. Analysis runs in the background, so it does not block the web request.

## 3. 技术难点

**What was the biggest challenge?**

> One key challenge was keeping measurements, manual reviews, and exported results consistent. The system stores raw measurements separately from review decisions and uses fixed review versions for comparisons and exports. This makes results easier to reproduce and audit.

## 4. 设计取舍

**Why did you choose this approach?**

> The project starts with a deterministic pipeline because its behavior is easier to explain and verify. This allows the workflow and data contracts to be tested before introducing a trained model.

## 5. 功能亮点

**What makes this project useful?**

> Users can click a summary metric and inspect the underlying objects in the image. They can also review uncertain results and compare two regions using fixed versions. This connects the numbers with the visual evidence.

## 6. 后续改进

**What would you improve next?**

> I would first evaluate the pipeline on representative real data with independent annotations. Then I would improve segmentation and marker classification, and add support for larger images and batch processing.

## 7. 优先记忆的关键词

| English | 中文含义 |

| Background processing | 后台处理：分析任务不阻塞网页请求 |

## 8. 表述边界

- 当前使用合成数据和确定性模拟分析器，不是训练好的医学 AI 模型。
- 已实现的工程流程不等于经过医学性能验证；不要声称诊断准确率或临床效果。
- 尚未实现的真实数据验证、大图处理和批量分析，应作为后续改进来介绍。
- 使用 “I designed” 或 “I implemented” 时，只描述自己实际完成的工作。
