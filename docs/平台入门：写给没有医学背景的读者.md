# 从一张组织图像开始：看懂 OncoMosaic 平台

**适合谁读：** 没有医学背景，希望理解这个平台为什么要做、能帮人做什么的读者。

本文按理想平台的设计目标讲解，不要求你理解代码或算法公式。贯穿全文的问题是：**肿瘤相关组织中，上皮与 T 细胞候选对象有多少，它们怎样分布、彼此有多接近？** 文末会简要说明当前演示系统与目标的关系。原始项目背景和完整教学案例见[项目背景与研究故事](guide/00-项目背景与研究故事.md)。

## 1. 先认识一个研究场景

假设一位研究者拿到了一份肿瘤相关组织样本。他想知道：

> 这个区域里有哪些细胞？其中某类免疫细胞多不多？它们集中在哪里，距离其他细胞有多远？

回答这些问题，需要把样本制成适合显微观察的图像，再识别其中的对象，逐个测量，最后汇总。

你可以把这项工作想象成阅读一张非常细密的地图：先确定地图上哪些区域值得研究，再找出不同类型的对象，统计数量和位置。这里的对象是组织中的细胞，地图则是经过实验处理和成像得到的组织图像。

**OncoMosaic 的目标，就是帮助研究者把这张图像变成能够查看、核对和比较的数据。**

### 目标新增：观察 Ki-67 增殖标记

除了数量和位置，平台计划加入 Ki-67，观察不同对象群的核内增殖相关信号。它像是给已有对象补上一项状态：一个上皮候选可以 Ki-67 阳性，一个 T 细胞候选也可以阳性。身份与这项状态要分别解释，不能看到 Ki-67 阳性就认定是肿瘤。

页面应告诉你“哪一群对象、其中多少可以评价、有多少阳性”，而不只显示一个百分比。例如 30 个阳性、60 个阴性、10 个无法判定，对可评价的 90 个对象计算，比例是 33.33%。未做该项检测时显示“未检测”。这些是目标设计；现有程序已实现 Ki-67 首期模拟功能。详见 [Ki-67 功能设计](Ki67功能设计.md)。

## 2. 为什么研究肿瘤时还要看周围的细胞

人体组织由许多细胞及其周围结构组成。一份肿瘤相关组织中，也可能同时存在免疫细胞、血管和起支持作用的组织。

免疫细胞参与身体的防御活动。T 细胞是其中一类，不同 T 细胞的作用和状态并不完全相同。研究者会关注它们出现在哪里、数量如何，以及它们与其他细胞的关系。

肿瘤细胞及其周围的细胞、血管和其他成分共同构成的环境，称为**肿瘤微环境**。第一次看到这个词，只要把它理解为“肿瘤及其周围的局部环境”即可。[NCI：肿瘤微环境](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/tumor-microenvironment)

例如，两块组织里都观察到 100 个某类免疫细胞，但一块组织面积大、另一块小；或者一块中的细胞聚在边缘，另一块分散在内部。它们的数量相同，分布情况却不同。因此研究者往往同时需要数量、密度和位置关系。

这些观察有助于研究，但某类细胞“更多”或“更近”是否有特定医学意义，需要结合具体研究证据解释。

## 3. 图像是怎样来的

### 第一步：把组织制成可以观察的薄片

从组织样本制作的薄层截面叫**组织切片**。显微图像展示的是这个截面，因此看到的形状不一定是一个完整细胞的全部轮廓。

细胞里面的细胞核含有大量遗传信息。找到细胞核常常有助于定位细胞，但核只是细胞的一部分：圈出了核，不等于已经圈出了整个细胞。

### 第二步：让想观察的目标更容易看见

组织里的许多分子，单靠普通外观不容易辨认。实验人员可以用特定试剂，让希望观察的目标产生可检测的信号。

其中一种方法叫**免疫荧光**：利用抗体帮助识别目标，再通过荧光信号观察它。抗体可以先理解为用于识别特定目标的实验工具，荧光则是在合适光照下发出的光。

同时观察多项标记，叫**多重免疫荧光**。实验是否可靠，需要相应对照和验证，不能只凭图像颜色鲜艳来判断。[SITC：染色与验证建议](https://jitc.bmj.com/content/8/1/e000155)

### 第三步：设备记录光，形成数字图像

成像设备把不同位置的光信号记录下来。平台接收到的是这些数字图像，以及解释图像所需的实验资料。

```mermaid
flowchart LR
    A[组织样本] --> B[制作薄片]
    B --> C[染色以观察目标]
    C --> D[设备采集图像]
    D --> E[平台分析并供人核查]
```

因此，软件分析之前已经有一段实验过程。图像质量、染色质量和采集方式，都会影响后面的结果。

## 4. “多靶点”和几个字母分别是什么意思

这里的**靶点或标记**，可以理解为“本次想观察的分子或结构”。“多靶点”表示同时观察多项，并不表示检测了多种肿瘤，也不直接表示选择治疗药物。
本平台围绕 DAPI、panCK、CD3、CD8 信号进行光谱成像分析。常说的“四标记”更具体是三项抗体标记加一种核染料；它们不是四个评分结果，数量、密度和距离才是后续统计指标。

以 DAPI、panCK、CD3、CD8 为例，不需要背全名，先记住它们提供什么线索：

| 名称 | 可以先这样理解 | 需要注意什么 |
|---|---|---|
| DAPI | 帮助看见细胞核的染料 | 找到核，不等于得到了完整细胞边界 |
| panCK | 帮助观察上皮相关特征；上皮是覆盖表面、形成腺体等结构的一类组织 | 正常上皮也可能有这种信号，不能直接把阳性叫作肿瘤 |
| CD3 | 帮助识别 T 细胞相关特征的标记 | 需要结合其他证据判断 |
| CD8 | 与 CD3 等组合，帮助描述某些免疫细胞亚群 | 不能只凭它认定细胞身份或正在发挥杀伤作用 |

这些标记的技术解释与资料来源见[医学知识章节](guide/02-医学概念与算法边界.md)。

**“阳性”**在这里表示检测信号符合规定的判定条件，通常写成上标“⁺”。例如“CD3⁺CD8⁺”表示同时满足这两项阳性条件。它不是在说患者“检测出某种疾病”。

一组共同使用的标记叫**面板**。根据这些标记组合描述对象的类别，叫**表型**。阅读平台时，可以把“表型识别”理解成“依据已观察到的特征给对象分类”。

如果证据还不足以确定身份，平台可以使用“候选对象”或“无法判定”。这种表述保留了进一步核查的空间。

### 为什么选择这四项就能形成一个研究故事

DAPI 帮助确定对象的位置；panCK 提供上皮相关线索；CD3 找出 T 细胞候选；CD8 配合 CD3 再区分一个研究关注的亚群。这样既能描述组织中的候选细胞组成，也能比较两类对象的空间关系。

多项标记的价值体现在**同一个对象的联合判断**。例如对象 17 的 CD3 和 CD8 都满足阳性条件，才能称为 CD3⁺CD8⁺ 候选对象。旁边另一个对象的 CD8 信号，不能借给对象 17 使用。算法因此需要先找对象，再测量属于它的信号。

这套面板适合讲清范围明确的研究故事，没有覆盖全部免疫细胞种类。三项抗体标记都阴性的对象仍可能是其他细胞；CD3 阳性而 CD8 阴性，也不能自动称为 CD4 阳性，因为本次没有检测 CD4。

## 5. 高光谱为什么会出现在这个平台里

普通彩色图像常用红、绿、蓝三个通道表示颜色。光谱图像则在多个波长范围记录强度，可以把它理解为：对每个位置的光，记录得更细。

**高光谱**强调对光谱进行较密集、较窄波段的采样。它带来的是更多关于光的观测信息。

为什么需要这些信息？因为不同荧光来源可能在相近波长发光，信号会混在一起，组织自身也可能发光。算法需要利用参考资料，估计各项标记分别贡献了多少信号，这个过程叫**光谱解混**。

可以用同时听到多种乐器作类比：我们希望借助各自的声音特征，区分不同来源。但真实分析能否分清，仍取决于采集质量和参考资料是否合适。

理解三者的分工即可：

- **染色**：让希望观察的目标产生信号。
- **光谱成像**：记录这些光信号在不同波长下的情况。
- **分析算法**：分离信号，再识别、测量和统计图像中的对象。

采用多重免疫荧光染色，通过不同荧光染料标记 panCK、CD3、CD8 等生物标志物，并使用 DAPI 对细胞核进行复染；高光谱成像后通过光谱解混获得各标记物的独立信号图。

波段数量与标记数量是两回事。记录了 24 个波段，不代表检测了 24 种蛋白，也不代表系统自然知道哪一个对象是肿瘤细胞。

## 6. 为什么要设计这样一个平台

当图像数量增加，研究者需要解决几类重复出现的问题：

| 研究中的困难 | 平台希望提供的帮助 |
|---|---|
| 一幅图里有很多对象，逐个寻找和测量费时 | 自动找出对象并形成测量表，供人工核查 |
| 实验、图像和算法资料分散 | 把图像与对应的面板、批次、分析方法关联起来 |
| 不同人统计的范围和标准可能不同 | 明确区域、对象定义和统计分母，保存所用方案 |
| 一个数字出错时，不容易知道原因 | 从汇总数字定位到对象，再回到原图查看依据 |
| 人工改过结果，但修改过程容易丢失 | 保存自动结果、人工修改和报告版本 |

平台的理想价值是：让研究者更有条理地分析图像，让重复工作更高效，让结果更容易解释和复查。是否真正节省时间、提高一致性，还需要在实际使用中评价。

## 7. 理想平台应具备哪些功能

### ① 接收图像，并知道它来自什么实验

除了原始图像，还需要知道用了什么标记、哪些波长、图像的实际尺寸，以及相关对照和采集信息。

可以把这些资料理解为图像的“说明书”。缺少说明书，即使图片能打开，也不一定能正确解释其中的数字。OME-TIFF 是可用于保存这类显微图像的格式之一；入门时不必掌握其文件细节。

```
组织切片与已确定的研究范围
  ↓
DAPI + panCK/CD3/CD8 等多重荧光染色
  ↓
高光谱显微镜采集
  ↓
原始 OME-TIFF + 实验与参考光谱资料
（例如 24 个波段）
  ↓
Python / 高光谱算法
  ↓
光谱解混
  ↓
DAPI / panCK / CD3 / CD8 独立通道
  ↓
核/细胞对象定位与分割
  ↓
逐对象测量 + 多项标记联合判定
  ↓
候选表型、数量、密度与空间结果
```

这里的“分割”是给对象圈出范围，“测量”是取出属于它的信号，“判定”是依据测量给出候选类别。三步相互依赖。确认恶性肿瘤细胞还需要病理证据，不能由这个流程图中的名称直接保证。

### ② 检查哪些地方适合分析

平台应提示模糊、过亮、明显异常或不适用的部分。这叫**质量控制**，简称质控。

它还应帮助区分有用组织与空白等区域。按研究需要识别更细的组织分区时，应有相应数据、验证和专业复核。

### ③ 找到对象，并圈出边界

算法需要找出细胞核，或在数据支持时圈出完整细胞。给每个对象画出属于它的范围，叫**分割**。

两个对象挤在一起时，系统可能把它们认成一个；很弱的信号也可能漏掉。因此边界应能显示出来，让人检查。

### ④ 测量标记，判断候选类别

平台应显示每个对象有哪些标记信号、测量值是多少，并依据规定条件形成候选类别。证据不足时，应允许无法判定。

分类结果应与测量依据关联，不能只给出一个无法核查的名称。

### ⑤ 统计数量、密度和位置关系

研究者可以圈定**感兴趣区域**，常写作 ROI，也就是“这次只分析的范围”。平台在这个范围内统计对象，并说明面积、分母和排除情况。

### ⑥ 支持人工修正和报告导出

理想平台应允许专业人员修正类别、补充漏掉的对象，或修改不合适的边界与组织区域。修改后，相关测量和统计应一起更新。

最终报告不仅展示数字，还保留图像、分析方法及修订版本，让别人知道结果是怎样得到的。

## 8. 深度学习在其中做什么

可以把深度学习理解为：让计算机从大量示例中学习，怎样完成特定识别任务。

训练时，专业人员提供图像和参考标注，例如“这一圈是一个核”“这部分属于某类组织”。模型学习后，再对没有见过的图像进行预测。评价时，要用没有参加训练的样本检查它是否可靠。

在这个平台中，它可以帮助识别组织区域、找到对象边界、判断某些质量问题或候选类别。光谱处理、统计公式和版本管理也可以由其他算法与普通程序完成。

例如，分割模型可以先提出对象边界；程序再测量这个范围里的 CD3 和 CD8 信号，按经过验证的规则判断双阳性。用不用深度学习，要看任务和数据；“多靶点分析”的含义来自联合测量与识别能力。

从使用者角度，重点是：**算法是否找对、测对、能指出不确定，并允许人检查。** 不需要先理解神经网络内部结构。

## 9. 跟着研究者看一遍结果

回到开头的场景。研究者导入一幅图，圈出一个区域，系统完成分析后，他应能看到：

1. **一张可查看的图**：标出了区域、对象轮廓及候选类别。
2. **一份对象表**：能查到每个对象的位置、标记测量和质量状态。
3. **一份区域汇总**：展示数量、比例、密度和空间指标。
4. **一份分析记录**：说明使用了什么图像、方法，以及人工改过什么。

下面用一组纯教学数字区分常见指标，它们不是医学正常值，也不是当前样例的实际结果。

假设有效分析面积为 0.1 平方毫米，里面有 100 个可分类对象，其中 20 个属于某类候选 T 细胞：

| 指标 | 示例结果 | 回答的问题 |
|---|---|---|
| 数量 | 20 个 | 找到了多少个这类对象？ |
| 比例 | 20 / 100 = 20% | 在这 100 个可分类对象中占多少？ |
| 密度 | 20 / 0.1 = 200 个/平方毫米 | 平均每单位有效组织面积有多少？ |
| 距离 | 另行根据对象位置计算 | 指定两类对象之间有多近？ |

这里的 20% 不是“所有 T 细胞中占 20%”，因为分母采用了全部可分类对象。排除和无法判定的对象也应另外说明。

查看距离时，还要知道测的是核中心之间的距离，还是细胞边界之间的距离。两种定义不能混用；没有可配对对象时，应说明无法计算，不能填成零。

### 数量相同，空间故事也可能不同

再假设区域 A、B 的有效面积均为 0.1 mm²，都有 100 个可分类对象，其中 20 个是 CD3⁺CD8⁺ 候选对象。两者比例都是 20%、密度都是 200 个/mm²。如果 A 中这类对象到最近上皮候选对象的平均核中心距离为 12 µm，B 为 40 µm，它们在空间分布上仍然不同。

这是教学假设，可描述 A 中两类对象平均更接近；不能直接说 A 的免疫杀伤更强。距离还受区域范围和可配对对象影响，跨区域比较前应统一分析方案。完整案例见[研究故事第 5 节](guide/00-项目背景与研究故事.md#5-用一份教学报告理解数字)。

## 10. 读到这里，记住几个容易混淆的地方

| 容易产生的理解 | 更准确的理解 |
|---|---|
| 图上很亮，就一定有很多目标蛋白 | 亮度还受染色、设备和处理方式影响，要结合条件解释 |
| panCK 阳性就是肿瘤 | 它提供上皮相关线索，判断肿瘤需要更多证据 |
| 两类细胞靠得近，就在相互作用 | 距离是空间观察，具体生物学作用需要额外证据 |
| 圈出一个核，就等于分出了完整细胞 | 核与细胞边界是不同层次 |
| AI 给了类别，就一定正确 | 模型可能出错，需要独立评价和人工核查 |
| 平台生成报告，就能直接用于诊断 | 研究定量结果用于临床决策还需要相应验证 |

关于实际图像分析的专业建议，可进一步阅读 [SITC 图像分析指南](https://jitc.bmj.com/content/13/1/e008875)；首次阅读本文不需要展开其中技术细节。

## 11. 目标设计与当前演示是什么关系

本文介绍的是理想平台希望具备的能力。当前仓库使用程序生成的模拟图像和确定性分析方法，演示导入、分析、复核、同图像双区域比较与导出的流程；没有训练好的真实医学深度学习模型，也没有真实患者数据上的性能结论。

现在可以在页面上比较两个观察区域的数量、比例、密度与距离，并点击指标或距离区间找到对应对象和最近邻连线。这让“数字从哪里来”也能实际演示；操作见[双区域比较与对象探索](guide/03-核心功能与截图演示.md#7-多区域比较与对象联动探索)。

可以把当前演示理解为用于展示工作流程的样板。完整目标中的组织识别、可靠细胞分割及更丰富的人工编辑等能力，需要继续建设和验证。具体完成范围见 [项目规格](../SPEC.md)。

## 12. 一分钟回顾

这个平台围绕一张经过染色与光谱采集的组织图像，帮助研究者找区域、找对象、看标记、算数量与位置关系，再由人核查并形成报告。

理解它只需要先记住五点：

1. 组织里有多种细胞，研究者关心它们的数量和分布。
2. 染色提供观察目标的信号，光谱成像记录这些信号。
3. 算法将图像转成区域、对象和测量结果。
4. 报告里的数字必须说明范围、单位和统计口径。
5. 人工复核与结果追溯是平台的重要功能。
