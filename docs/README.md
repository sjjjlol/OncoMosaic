## 文档维护约定

- `architecture/` 解释当前四层实现与取舍；`guide/` 包含背景、目标设计和讲解材料，阅读时注意各篇的现状说明。
- `Elekta/` 是辅助学习资料，示例工程独立于 `backend/OncoMosaic.slnx`，不作为主应用服务启动。
- 示例的源码、项目文件、预期输出和必要参考图片纳入 Git；构建产物、IDE 配置和个人简历原件留在本地。
- 本仓库未收录的个人经历原始笔记用文字注明，不提供依赖个人电脑目录的失效链接。
- 截图与验证 JSON 保留原有路径，便于已有文档继续引用；记录中的日期和版本代表当次验证，不自动代表当前环境。
