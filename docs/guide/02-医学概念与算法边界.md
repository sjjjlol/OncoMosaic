# 02 平台需要的医学知识与理想算法功能

[返回手册](../PROJECT_GUIDE.md) · [上一章](01-项目架构与数据模型.md) · [下一章](03-核心功能与截图演示.md)

本章说明一个合理的“多靶点定量分析＋光谱成像平台”应该理解什么、具备什么能力。以下是**目标功能设计**，不表示仓库已经实现。我们假设具备质量合格的染色图像、实验对照和专业标注，重点讨论平台和算法的职责，不展开网络结构、训练技巧或代码参数。

初次阅读时，可先读[第 00 章的研究故事](00-项目背景与研究故事.md)，再用本章解释其中的概念。现有面板围绕“上皮与 T 细胞候选对象的组成及空间关系”展开。

## 1. 平台要回答哪些问题

研究者拿到一张组织切片，希望知道：**哪些区域值得分析，里面有哪些细胞，它们表达哪些标记，数量和位置关系如何。**

例如，在一个经过确认的肿瘤相关区域内，研究者可能希望统计上皮候选细胞和某类 T 细胞的数量、单位面积密度，以及两类细胞之间的距离。平台应让研究者从汇总数字回到具体区域和具体对象，查看并修正分析依据。

“多靶点”在这里指同时观察多项分子标记。“定量”指将观察转成强度、数量、比例、密度和空间指标。这些指标服务于研究问题；诊断或疗效预测需要另外建立相应证据。

## 2. 理解平台所需的医学概念

| 概念 | 需要理解的含义 | 对平台设计的影响 |
|---|---|---|
| 组织切片 | 组织的薄层截面，包含多种细胞及周围结构 | 图像中的二维对象不等于完整三维细胞 |
| 细胞与细胞核 | 核是细胞的一部分，核外还有胞质及细胞膜等结构 | 定位核和确定完整细胞边界是不同任务 |
| 标记 / marker | 用来观察某种分子或结构的检测指标 | 每个标记需要有清楚的实验来源与解释 |
| 染色面板 / panel | 一起检测的一组标记 | 面板决定能够区分哪些对象，不能任意推断未检测的身份 |
| 表型 / phenotype | 按标记组合及相关特征描述的对象类别 | 分类应结合多项证据，并允许无法判定 |
| 肿瘤微环境 | 肿瘤细胞及其周围免疫细胞、血管、间质等共同构成的环境 | 需要同时观察不同对象及其空间关系 |
| ROI / 感兴趣区域 | 研究者或算法选定的分析范围 | 计数、面积和距离都必须明确属于哪个范围 |
| 质控 / QC | 检查图像及分析结果是否适合当前任务 | 不合格或不确定的区域应被标出，不能默默进入统计 |

肿瘤微环境的基本定义可参考 [NCI 词典](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/tumor-microenvironment)。

### 以 DAPI、panCK、CD3、CD8 为例

| 标记 | 可以帮助观察什么 | 解读时应保留的边界 |
|---|---|---|
| DAPI | 细胞核位置和形态 | 显示核，不直接给出完整细胞边界 |
| panCK | 上皮相关特征 | 正常上皮也可能阳性，不能单凭它认定肿瘤 |
| CD3 | T 细胞谱系相关特征 | 需要结合其他标记、形态及实验质量解释 |
| CD8 | 与 CD3 等组合，描述相关免疫细胞亚群 | CD8 单阳性不能直接证明 T 细胞身份或杀伤功能 |

因此，合理的输出可以是“panCK⁺ 上皮候选对象”“CD3⁺CD8⁺ T 细胞候选对象”。如果希望输出“肿瘤细胞”，还需研究适用的形态、标记及病理区域证据。面板扩大后，可以支持更多类别，但每个新增类别都需要对应的实验与标注依据。

标记基础资料：[DAPI 核染色说明](https://www.thermofisher.com/de/en/home/life-science/cell-analysis/fluorophores/dapi-stain.html) · [panCK 上皮来源标记说明](https://tools.thermofisher.com/content/sfs/brochures/IHC03440_Visualizing_Expression2014.pdf) · [T 细胞组合标记说明](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/flow-cytometry/flow-cytometry-learning-center/flow-cytometry-resource-library/flow-cytometry-multiplex-panels/human-nk-t-cell-panel-22.html)。这些资料用于解释标记含义，不表示直接采用对应产品或流式面板就能验证本平台的组织成像方案。

### 标记、抗体、染料和通道有什么区别

以 CD3 为例：CD3 是希望检测的目标；相应抗体帮助识别目标；配合的荧光染料产生可采集的光信号；解混后的 CD3 通道图展示这一检测信号的空间分布。DAPI 则直接作为核染料与 DNA 结合，不是第四项抗体。

这里的“四标记面板”是 DAPI 加三项抗体标记。采集设备可能记录更多波段，每个波段仍可能包含多种来源。显示图上的蓝、绿、红等颜色可以由软件指定，不能只凭颜色认定生物学身份。

### 从四张图到同一个对象的联合表型

分别统计四张图中的亮点，只能得到各自的信号分布。要说某个对象 CD3⁺CD8⁺，必须确认两项信号属于同一个对象。这要求标记图对齐、对象边界合理，并使用合适的测量区。

下面按核锚定对象举例。三项阳性/阴性状态是假设，实际判定还需检查质量；它不是医学标准阈值表。

| 对象 | panCK | CD3 | CD8 | 可以形成的候选表型 |
|---|---|---|---|---|
| A | 阳性 | 阴性 | 阴性 | 上皮候选 |
| B | 阴性 | 阳性 | 阳性 | CD3⁺CD8⁺ T 细胞候选 |
| C | 阴性 | 阳性 | 阴性 | CD3 单阳性 T 细胞候选，不能直接称为 CD4⁺ |
| D | 阴性 | 阴性 | 阴性 | 面板内阴性，具体身份未知 |
| E | 阳性 | 阳性 | 阳性 | 线索冲突，需核查邻近信号、分割和染色 |

从集合看，CD3⁺CD8⁺ 对象是 CD3⁺ 候选集合中的一部分。当前程序给对象一个互斥标签，因此统计中的 `cd3` 指 CD3 单阳性类别；按当前规则统计全部 T 细胞候选时，应同时考虑 `cd3` 与 `cd3-cd8`。逐对象标记测量仍分别保留，不会因标签互斥而丢失。

### 强度、阳性和比例是三层信息

**强度**是从规定测量区取得的连续数值。**阳性**是用阈值或其他经过验证的判定方法把信号转成状态。**比例**是某类对象数除以一个明确的对象集合。

例如，一个对象的 CD3 相对强度是 0.51，而教学阈值是 0.35，规则会将它判为阳性。这不表示“有 51% 概率是 T 细胞”，也不表示蛋白浓度为 0.51。阈值应结合对照、染色条件和验证确定；当前演示阈值没有真实组织评分依据。

### 肿瘤区域、上皮对象与有效组织的区别

| 名称 | 在分析中是什么意思 | 能否由现有标记直接保证 |
|---|---|---|
| 肿瘤相关样本 | 来自肿瘤研究场景的样本，仍可含正常组织及免疫、间质成分 | 样本来源需有记录 |
| 肿瘤区域 | 依据病理证据等确认的组织区域 | 需要专业确认或经验证的区域模型 |
| 上皮候选对象 | 根据 panCK 等线索形成的对象类别 | panCK 提供线索，不能单独确认恶性 |
| 有效组织区域 | 按方案保留、适合本次测量的组织像素 | 需定义并核查，不等同肿瘤区域 |

因此，报告“ROI 内上皮候选对象密度”与报告“肿瘤区域内某类细胞密度”需要不同的区域依据。当前代码只估计有效组织；手动给 ROI 起名为 `tumor-candidate` 不会产生肿瘤组织分区。

## 3. 多重免疫荧光与高光谱各负责什么

**多重免疫荧光负责让多个目标产生可区分的信号；光谱成像负责记录不同波长下的信号；分析系统负责把信号转成对象和定量结果。**

荧光标记的光谱可能互相重叠，组织自身也可能发光。高光谱通过较密集的波段采样提供更丰富的光谱信息，帮助分离这些来源。波段数表示采集了多少份光谱观测，不等于检测了多少种蛋白。

例如，用多个波段观测四项标记时，算法需要得到四项标记各自的信号分布，并处理背景和自发荧光，而不是简单把某一个波段直接命名为 CD8。

```mermaid
flowchart LR
    A[组织与染色面板] --> B[多波段光谱采集]
    B --> C[信号分离与质控]
    C --> D[组织分区与细胞分析]
    D --> E[标记测量与表型识别]
    E --> F[区域及空间统计]
    F --> G[可复核报告]
```

单染对照用于了解各个荧光来源；未染及其他适当对照帮助评估背景和染色可靠性。理想平台应管理这些资料，并将它们与采集批次关联。染色面板及其对照需要实验验证。[SITC 染色与验证建议](https://jitc.bmj.com/content/8/1/e000155)

## 4. 理想平台需要哪些数据

| 数据 | 主要作用 | 在流程中的位置 |
|---|---|---|
| 多波段组织图像 | 提供每个位置的光谱观测，保留原始可分析强度 | 每次分析的核心输入，可采用 OME-TIFF 等显微图像格式 |
| 实验与采集资料 | 说明样本、切片、面板、波长、像素尺寸、设备和批次 | 每次分析随图关联，决定像素如何解释 |
| 对照与参考光谱 | 支持信号分离、背景处理及实验质控 | 可按实验批次建立后供多张图像使用 |
| ROI 与区域资料 | 说明分析范围、已知组织区域及排除范围 | 由研究者提供或由模型预测后复核 |
| 专业参考标注 | 给出组织区域、核/细胞边界、表型和质量问题的参考答案 | 用于训练、调参与独立评价，不作为待测样本的答案输入 |
| 病例及研究分组资料 | 支持跨样本比较与研究设计 | 仅在相应研究需要且具备使用条件时关联 |

训练阶段，模型需要图像和对应参考标注。使用阶段，模型应从待分析图像及必要实验资料产生结果，不依赖这张图的人工答案。评价阶段，再用独立保留的标注判断结果是否达到预定要求。

## 5. 深度学习分析系统应实现哪些功能

下面按研究者能看到的效果定义功能。一套系统可以由多个模型和常规计算模块协作完成；无须要求全部功能由一个神经网络包办。

| 功能 | 期望实现的效果 | 应交付的结果 |
|---|---|---|
| 图像质控 | 发现失焦、饱和、明显伪影、异常背景及不适用输入 | 质量状态、问题位置、原因和可分析范围 |
| 光谱分离 | 将混合观测转换为各项标记信号，减少串色及背景干扰 | 可定量的标记图、背景估计和分离质量信息 |
| 组织分区 | 找出有效组织；按研究需要区分肿瘤相关区、间质、坏死或其他区域 | 区域掩膜、类别、面积和待复核区域 |
| 核/细胞实例分割 | 找到每个对象的位置与边界，尽量减少漏检、重复和粘连 | 唯一对象编号、轮廓、中心、面积及边界质量 |
| 逐对象标记测量 | 将各项信号归属到合适的核、胞质或膜区域 | 每个对象的标记强度、测量区域及测量单位 |
| 表型识别 | 依据面板、标记组合与必要形态信息区分对象 | 类别、判定依据及无法判定状态；如提供概率，需验证其可信度 |
| 区域与空间定量 | 计算各类数量、比例、密度及位置关系 | 带分母、单位和区域定义的统计表及空间图 |
| 复核与追溯 | 让研究者核查、纠正并重算结果 | 自动结果、人工修订、模型/参数版本及导出报告 |

其中，组织分区和实例分割常适合由深度学习承担；光谱处理、标记测量、表型判定可按数据条件选择适当方法；统计和版本管理通常由确定性的计算与平台服务完成。平台关注的是输出是否可靠、可解释和可复核。

### 三个关键功能约束

**对象边界应与数据能力匹配。** 有可靠膜/胞质信号及参考标注时，可以追求完整细胞分割；只有核信号时，应明确输出核及近似测量区，不能把推测边界包装成确定的细胞膜。

**算法需要表达不确定。** 混合信号、边界不清或不适用的样本应能进入待复核状态。强行给每个对象一个确定身份，会把不确定性隐藏在最终统计里。

**复核应能影响最终结果。** 理想平台除了改类别，还应根据任务需要支持补录漏检、拆分粘连、修改边界和修正组织区域，并在修改后重算受影响的指标。

## 6. 平台调用算法时，输入输出应是什么

这里是目标接口的业务含义，不限定具体 Python 类、网络结构或字段拼写。

### 输入：图像、实验解释和分析要求

一次调用应提供：

- **图像引用**：原始多波段图像或受控存储中的图像标识。
- **采集与染色信息**：波长、像素尺寸、强度单位、标记面板、设备及批次。
- **校准资料**：适用的参考光谱、背景和对照结果。
- **分析范围与任务**：ROI、需要的组织类别、目标表型、统计要求。
- **分析版本**：模型与配置版本，便于复算和比较。

大图像适合通过文件或对象存储传递，调用消息传引用和必要参数。

### 输出：图像层、对象层、汇总层和质量层

| 输出层 | 内容 | 平台如何使用 |
|---|---|---|
| 图像层 | 定量标记图、组织区域图、核/细胞实例图、可视化叠加图 | 显示通道、区域和对象边界，支持定位与复核 |
| 对象层 | 对象 ID、坐标、边界、所属区域、各标记测量、表型、质量状态 | 点击查看、筛选、人工修改和逐对象导出 |
| 汇总层 | 各区域的面积、计数、比例、密度及空间指标 | 形成研究报告与样本比较表 |
| 质量与追溯层 | 失败原因、排除范围、不确定对象、输入和模型/参数版本 | 解释结果是否可用、如何产生以及怎样复现 |

算法服务可以返回文件清单及对象表，由平台再计算汇总；也可以同时返回汇总。无论采用哪种分工，统计口径都应一致。用于定量的结果应与显示图片区分，并保留足够数据供核查和复算。

## 7. 最终报告应能回答什么

| 研究问题 | 合理指标 | 报告需要同时说明 |
|---|---|---|
| 某类对象有多少？ | 数量 | 哪个区域、怎样识别、哪些对象被排除或无法判定 |
| 某类对象占多少？ | 比例 | 分母是全部可分类对象、某个细胞群还是其他集合 |
| 该区域分布多密？ | 对象数 / 有效组织面积 | 面积单位及空白、坏死、伪影的处理规则 |
| 两类对象有多接近？ | 最近邻距离、邻域内数量等 | 起点和目标类别、核中心或细胞边界距离、ROI 边缘处理 |
| 不同样本能否比较？ | 按同一方案获得的统计 | 染色与设备条件、校准、区域选择及分析版本 |

例如，“CD3⁺CD8⁺ 候选对象密度”需要对象身份和有效组织面积都可靠；“距离较近”表示空间接近，不能单独证明免疫杀伤或预测治疗效果。

### 三种分母与一个空间方向

| 想问的问题 | 分母或计算方向 | 是否为当前默认汇总 |
|---|---|---|
| CD3⁺CD8⁺ 候选在可分类对象中占多少？ | 全部可分类且未排除对象数 | 是 |
| CD3⁺CD8⁺ 候选在 T 细胞候选中占多少？ | 同口径下 CD3 单阳性与 CD3⁺CD8⁺ 候选对象数之和 | 否，需要另外计算并注明 |
| CD3⁺CD8⁺ 候选分布多密？ | ROI 内有效组织面积，单位 mm² | 是 |
| 这类对象离上皮候选多近？ | 逐个 CD3⁺CD8⁺ 对象寻找最近的不同 panCK⁺ 对象，再汇总核中心距离 | 是 |

从 T 细胞候选到上皮候选的平均最近邻距离，与反方向的结果通常不同，因为起点集合不同。局部视野外的邻居不可见，边缘处理也会影响比较。理想系统需要按研究方案固定这些规则；当前只在 ROI 内配对，没有完整的跨视野或空间边缘校正。

## 8. 怎样判断算法达到了目标

验收应围绕实际功能，使用未参与开发的独立参考数据，按病例及相关批次合理划分，防止相似图块泄漏。

- **找区域是否可靠**：重要组织是否保留，空白和问题区域是否被正确处理。
- **找对象是否可靠**：漏检、误检、粘连及边界错误是否满足研究要求。
- **测量与分类是否可靠**：标记归属是否合理，各类误判和无法判定情况是否可接受。
- **最终数字是否可靠**：计数、面积、密度及空间指标与独立参考是否一致，重复分析是否稳定。
- **跨条件是否可用**：在声明支持的组织类型、设备和批次范围内，性能是否保持。

具体达标值应由研究用途和参考数据确定，不能预先用一个统一“准确率”概括全部能力。算法输出与图像分析质控的专业背景可参考 [SITC 图像分析建议](https://jitc.bmj.com/content/13/1/e008875)。

理想平台的完整交付是：**把多波段组织图像转化为可检查的组织区域、逐对象测量和表型，再形成口径明确、能够复核与追溯的定量结果。**
